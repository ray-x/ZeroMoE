# MoeStream MoeStream is an ultra-fast, zero-dependency inference engine written from the ground up in native C++ and CUDA. It is specifically designed to stream frontier-class Mixture-of-Experts (MoE) GGUF models on consumer-grade hardware. By implementing strict graph-level memory isolation, MoeStream maps and holds core persistent network blocks directly in physical VRAM and RAM, while dynamically streaming massive routed expert matrices directly from NVMe storage on an on-demand basis. --- ## Architectural Performance Foundations - **Zero-Dependency GGUF Engine:** Automatically parses binary tensor offsets and extracts embedded BPE tokenizers straight from the GGUF file metadata header array. No external json or weight config maps required. - **Lock-Free Asynchronous Prefetching:** Utilizes a highly optimized Single-Producer/Single-Consumer (SPSC) atomic ring buffer to dispatch prefetch instructions ahead of execution. It checks Layer $L$ activations against Layer $L+1$ router parameters to preload upcoming expert matrices via non-blocking DMA. - **Fused AVX-512 / VNNI Compute Core:** Eliminates intermediate vector allocation overhead by dequantizing GGUF blocks directly inside physical CPU registers using hardware-accelerated integer dot products (`_mm512_dpbusd_epi32`). - **RTX 3090 Integer Acceleration:** Features an advanced Ampere-native CUDA kernel leveraging the hardware-level `__dp4a` instruction alongside register warp-shuffles to handle dense projections instantly. - **MLA Weight Absorption:** Reduces the operational scanning footprint of Multi-head Latent Attention layers from $O(\text{Context} \times H \times D)$ down to a compact $O(\text{Context} \times \text{kv\_lora})$ by calculating attention directly in the lower-dimensional latent space. --- ## 📂 Repository Layout Tree ```text MoeStream/ ├── CMakeLists.txt # Unified C++/CUDA compiler configuration ├── setup.sh # Automated installation and toolchain builder ├── README.md # Engine configuration
